# ---------------------------------------------------------------------------
# Pylians build notes -- v0.12 does NOT build unmodified on this stack
# ---------------------------------------------------------------------------
# Pylians 0.12 pins Cython<3.0.0, which is unsatisfiable against numpy 2.x:
# numpy ships a deliberate trap in its Cython headers that aborts any build
# using Cython < 3. So build with Cython 3, plus three edits to setup.py:
#
#   1. cythonize(..., compiler_directives={..., "legacy_implicit_noexcept": True})
#      Restores Cython 0.x semantics where `cdef void f()` was implicitly
#      noexcept. Cython 3 defaults it to `except *`, which breaks the C
#      function-pointer assignments in integration_library.pyx (6 errors).
#   2. extra_compile_args_omp.append(omp_flag) -> .extend(omp_flag.split())
#      On Apple Silicon omp_flag is "-Xpreprocessor -fopenmp", passed as ONE
#      argv token; clang requires two.
#   3. extra_link_args = [omp_flag] -> omp_flag.split() + ["-lomp"]
#      The OpenMP runtime was otherwise never actually linked.
#
# Then, with the env active:
#   export CFLAGS="-I$CONDA_PREFIX/include" CPPFLAGS="-I$CONDA_PREFIX/include"
#   export LDFLAGS="-L$CONDA_PREFIX/lib -lomp"
#   pip install --no-build-isolation .
#
# Pylians then downgrades Cython to 0.29.37 as a declared runtime dep. Harmless
# (the extensions are already compiled), but bump it if anything needs Cython 3.
